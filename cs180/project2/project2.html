Part 1: Fun with Filters

Part 1.1: Convolutions from Scratch

I implemented convolution using both 4 for loops (naive) and 2 for loops (vectorized). I implement it with 0 padding for borders. Here is the comparison between the three versions using a 9x9 box blur filter on a selfie of myself.

The results are identical between implementations. One thing to note is the dark border around the blurred images. This is due to zero padding since the result of each little convolution dot product on the border is driven down by the 0s. If I had used another type of padding like extending the borders outwards, this effect would not be present. This is the same between images because every implementation is set to use zero padding.

From a performance perspective, the four-loop implementation is very bad. My two-loop implementation is alright and scipy's version is very fast. The runtimes are shown above. The Python-only four-loop version is extremely inefficient since it doesn't take advantage of vectorization and in general high-level language implementations of these kinds of things are slow. The two-loop implementation is much better since we're able to manipulate data in parallel using NumPy's vectorization abilities and many of the convolution operations are handled using low-level compiled code. The scipy implementation is the fastest since the whole convolution function is likely written in performance-friendly code abstracted away by the package and probably uses clever optimizations beyond the scope of the class.

Part 1.2: Finite Difference Operator

I convolve this image of a cameraman to demonstrate edge detection using convolution. I convolve using a basic [1, 0, -1] kernel for the partial derivative of the image wrt x and the transpose of this kernel for the partial derivative wrt y.

The binarized gradient has a cutoff value of 78. I chose this value because it gets rid of most of the noise while preserving the cameraman's edges. Unfortunately, some of the background is lost with this cutoff.

Part 1.3: Derivative of Gaussian Filter

To try and get better results, I try applying a Gaussian blur (13 kernel size and 2 std as parameters) before performing edge detection like in the last part. The idea is that the blur will help remove noise while preserving the real edges which should be sharper and remain visible after the blur.

The binarized gradient here has a cutoff of 30. We can observe that all of these post-filter results look much smoother and much of the noise in the grass is eliminated. This has the tradeoff though of making the background buildings less visible as well. Since a lot of the noise is gone, I'm able to choose a lower binarization threshold. Additionally, a lot of the existing edges in the gradient images are smoother after filtering.

Since convolution is associative and commutative, we can do the same thing by convolving the dx and dy filters with the Gaussian filter in advance to get derivative of Gaussian filters. So, instead of convolving twice (Gaussian then derivatives or vice-versa), we can convolve once (derivative of Gaussian only).

Demonstrating that this is the same, here are identical results (with the same binarization cutoff as well).

Part 2: Fun with frequencies

Part 2.1: Image Sharpening

I will use the unsharp masking technique to make images appear sharper. The idea of the technique is as follows: Blur the image to isolate the low frequencies. Subtract the low frequencies from the original image to isolate the high frequencies in the image. Add the isolated high freqneucies back to the original image with some scaling factor in order to artificially make the high frequencies stronger, creating a sharpening effect. Using some algebra, this can be combined into a single convolution operation where x is times and * is convolution:

img_sharpened = img + strength(img - (gaussian * img)) = ((1 + strength) x delta - alpha x gaussian) * img

Part 2.3: Gaussian and Laplacian Stacks

In this part, I implement Gaussian and Laplacian stacks for use in multiresolution blending in the next part. The Gaussian stack is built by convolving over the original image using Gaussian kernels with larger and larger sigma values. I scale the sigma by a factor of 2 each layer. The Laplacian stack is built by subtracting between the Gaussian stack layers and adding the bottom Gaussian to the end.
